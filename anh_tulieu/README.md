# Thư mục lưu trữ ảnh tư liệu làng Trường Lưu

Đặt các tệp ảnh tư liệu **bản đã giảm kích thước** (ví dụ `.jpg`, `.webp`, `.png` dung lượng tối ưu cho hiển thị web trên điện thoại) vào thư mục này (`/anh_tulieu/`).

Trong tệp `/tulieu.json`, mỗi bản ghi tham chiếu đến các tệp ảnh theo đường dẫn `/anh_tulieu/<ten-tep>.jpg`, kèm theo:
- `duongDanToanTrang`: đường dẫn ảnh toàn trang
- `duongDanCanCanh`: đường dẫn ảnh cận cảnh
- `chuThich`: chú thích hiển thị ngay dưới ảnh
- `nguon`: nguồn tư liệu hiển thị ngay dưới ảnh
- `laBanGiamKichThuoc`: `true`
